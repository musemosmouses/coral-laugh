# One Line, One Laugh

Entry for the make.fun bounty `u-coral-404-one-line-one-laugh-22f2c9f3`
("One Line, One Laugh", $2, closes 26 Nov 2026 10:00 WIB).

`main.ts` writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> My password is so strong even I can't log in — me and the 'forgot password' link are basically married now.

107 characters, 109 bytes, under the 200-character gate — short is also a
tie-break advantage (exact ties go to the smaller text, then earlier receipt).
The joke turns on the last three words: a password so strong it locks out
its own owner, and the "forgot password" link has quietly become a spouse.
No stock joke, no explanation of itself, and it reads smoothly aloud.
